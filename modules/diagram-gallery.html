C# 표기로 그린 개념·혼합 학습 모델의 관계·생명주기·실행 흐름을 검색하고 비교한다. UML 클래스·상태·활동 표기와 설명용 실행 흐름도를 구분해서 읽고, 구현 증거는 연결된 소스와 verifier에서 확인한다.

표기 기준 · C#Runtime Core Stat Effect Skill Combat Status SVG

다이어그램 목록

클래스와 인터페이스의 공개 멤버는 C# PascalCase를 사용한다. 비율이 긴 썸네일은 미리보기 안에서 스크롤할 수 있고, 클릭하면 화면 맞춤과 원본 100%를 전환해 자세히 확인할 수 있다.

표기와 증거 범위. 클래스·상태·활동 다이어그램은 OMG UML 2.5.1 명세의 해당 표기 의미를 기준으로 읽고, 단계가 세로로 이어지는 그림은 실행 흐름도로 구분한다. 기존 파일명의 *_sequence_diagram은 안정적인 산출물 ID일 뿐, lifeline과 message를 갖춘 UML sequence diagram이라는 뜻이 아니다.
이 갤러리의 모든 카드는 기본적으로 Conceptual/Mixed다. 도메인 태그(Stat·Skill·Combat·Status·Runtime)는 주제를 나타낼 뿐 구현 완료 배지가 아니다. 그림에는 현재 C# 계약과 함께 StatBlock·SkillTimeline·Status 저장소·durable outbox 같은 product 목표 타입이 섞여 있다. 39–41번도 실행 runtime의 원칙과 아직 필요한 production adapter를 함께 요약한다. 따라서 어떤 그림도 단독 실행 증거로 사용하지 말고, 각 학습 페이지가 Executable로 연결한 source/csharp·source/runtime와 verifier/test를 기준으로 판정한다.
